# Contributing

Thank you for improving codex-sdlc.

1. Open an issue before a large behavioral or schema change.
2. Create a focused branch from the default branch.
3. Run `npm ci` and `npm run verify`.
4. Add meaningful tests for runtime behavior and update user documentation.
5. Open a pull request that explains the concrete behavior change and validation performed.

Do not commit credentials, generated dependency directories, package archives, or repository data from real delivery runs. Schema changes must preserve explicit version boundaries and include an upgrade or compatibility plan.
