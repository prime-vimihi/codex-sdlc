# codex-sdlc 0.4.1 release evidence

Date: 2026-09-11

This release improves first-use onboarding for the public codex-sdlc plugin. It adds a public Getting Started guide, explains how the plugin skills and npm CLI work together, guides setup through a pinned `npx` fallback when no matching global CLI is available, and adds clearer single- and multi-repository starter prompts. Runtime schemas and delivery commands are unchanged from 0.4.0.
