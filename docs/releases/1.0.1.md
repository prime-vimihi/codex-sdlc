# codex-sdlc 1.0.1

Release date: 2026-10-05.

## Updated token-saving preset

`/sdlc --save-my-token` and `$sdlc --save-my-token` now configure BA to use `gpt-6.1-sol` with `high` reasoning. PM inherits its model, and backend, web/mobile frontend, and QC use `gpt-6-luna` with `xhigh` reasoning. Normal mode and optional AI Product Owner settings retain their existing behavior.

These IDs follow [official Codex model guidance](https://learn.chatgpt.com/docs/models), checked on 2026-10-05. GPT-6 Luna remains the current Luna model; no newer Luna ID is assumed. Host availability is still validated before dispatch, without an implicit fallback. Model selection does not establish a measured token or time reduction.

## Existing projects

Update both plugin and coordinator runtime to 1.0.1. The Plugins Directory version is submitted and published separately from GitHub and npm. Preview the project runtime upgrade:

```sh
npx --yes codex-sdlc@1.0.1 upgrade --root /absolute/path/to/coordinator --dry-run
```

Run the same command without `--dry-run`, restore the runtime, and run `doctor` and `validate-config` as described in the [upgrade guide](../getting-started.md#upgrade-an-existing-project).

Then reapply `/sdlc --save-my-token` in the coordinator to update its saved preset for new runs. Upgrading alone preserves project model configuration. Existing run snapshots and custom role/fallback selections retain their saved IDs until explicitly changed.

For local package testing, use the [tarball procedure](../cli-reference.md#try-the-local-package-in-an-unrelated-repository).

## Validation

The dependency lockfile now uses patched `fast-uri` 3.1.8. A clean installation reports no dependency vulnerabilities.

All 183 tests across 20 files, TypeScript checks, and the build passed. Both edited skills passed validation. A fresh 1.0.1 tarball installation and restored repository launcher passed preview-without-writes, preset saving, idempotent reapplication, and normal reset checks. Migration coverage verifies that prior run snapshots retain GPT-6 Sol and that a host without GPT-6.1 Sol cannot silently substitute another model. These checks validate routing and persistence; real-agent quality, latency, and token usage have not been measured for this update.
